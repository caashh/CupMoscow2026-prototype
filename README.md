# ВТБ Контекст — демонстрационный прототип (v7)

## Запуск
```bash
npm install
npm run dev
```

## Что показывает
Четыре клиентских сценария, каждый доходит до итогового статуса операции (выполнен / отменён / ожидание до точной даты):

1. **Покупка велосипеда** — смена номера < 48 ч (признак 9): первичный отказ по СБП → повтор на те же реквизиты и сумму → перевод выполнен.
2. **«Безопасный счёт»** — перевод себе из другого банка > 200 тыс. и новый получатель (признак 11): предупреждение → отмена / помощь / «Это мой перевод» с тремя вопросами → честный путь повтора, если клиент настаивает.
3. **Получатель в базе ЦБ** (признак 1): отказ → повтор → обязательное ожидание до конца следующего календарного дня с точной датой. Кнопки «ускорить» нет ни у клиента, ни у оператора.
4. **Захват аккаунта**: уведомление на основное устройство → «Это не я» (защита доступа) или «Это я» (подтверждение по каналу, устойчивому к перехвату).

На каждом шаге видны сумма, получатель, статус и история операции; есть отмена и обращение в банк. Под экраном — пояснение для жюри (клиенту не показывается).

Кабинет сотрудника: очередь, карточка кейса, хронология с действиями клиента, передача старшему антифроду / в ИБ / в поддержку, закрытие только с итогом расследования.

Все данные вымышлены. Интеграций с АБС, CRM, антифрод-системами и базами Банка России нет.
